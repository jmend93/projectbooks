# Codex Test Drive

A tiny static app you can run locally to understand Codex's typical workflow.

## Run it

```bash
python3 -m http.server 4173
```

Then open <http://localhost:4173>.

## What it does

- Lets you type a coding request.
- Generates a simple simulated step-by-step workflow.
- Saves your prompt + notes in `localStorage`.
